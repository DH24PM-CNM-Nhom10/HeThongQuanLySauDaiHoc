# Mã nguồn lưu trữ

Thư mục này giữ các bản cũ để đối chiếu, không tham gia bản dựng hiện tại.

- `frontend-api/`: các bản sao API trước đây nằm trong `UI/app/_api_backup`.
- `frontend-public/`: hai tệp cấu hình rỗng trước đây nằm trong `UI/public`, được đổi đuôi `.txt` để không bị hiểu là cấu hình đang dùng.

API đang hoạt động nằm trong `UI/app/api` và `api/src`. Không sao chép mã lưu trữ trở lại ứng dụng nếu chưa đối chiếu với phiên bản hiện tại.
